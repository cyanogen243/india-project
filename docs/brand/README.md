# The India Project brand assets

The source guide in this directory is the supplied, authoritative TIP brand
guide. Public logo derivatives live in `public/brand/`.

- `primary-logo.png`: circular campaign mark for hero and social use.
- `compact-logo.png`: compact navigation mark.
- `texture.webp`: optimized folk-pattern framing texture.
- `icons/*.png`: transparent, optimized crops from the supplied layered icon
  artwork.
- `source/`: untouched designer originals, including the master logo, texture,
  contact sheet, and `TIP Icons.psd`.
- Anton: short, uppercase campaign headlines.
- Inter: navigation, calls to action, body copy, reports, forms, and admin UI.

Approved palette:

- Azaadi Red `#E21F26`
- Saffron Orange `#FF6A00`
- Surya Yellow `#FFB21A`
- Royal Blue `#0D47A1`
- Jazba Purple `#3B1361`
- Ink Black `#0B0B0B`
- Warm Cream `#F6EFE2`

Do not redraw or recolour the logo. Patterns frame information; they do not
replace clean reading space. Web derivatives are resized and compressed only
for delivery, while untouched originals remain in `source/`.
