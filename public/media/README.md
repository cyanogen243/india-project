# Curated public media

Only redacted public derivatives belong here. Never add original evidence,
unblurred faces, identifying audio, precise locations, or private Drive links.

For each approved file, add a matching record to `content/media.json` with:

- a broad zone, not coordinates or a precise address;
- source and access metadata;
- redaction notes;
- legal-review status;
- at least two reviewers;
- a local `/media/...` file path.

Originals should remain in a separate private evidence archive with restricted
access and a custody log.
